# Minotaur Project Remastered for Apple v1.4.13

- The Mac, iPhone and iPad game pickers show the app version in the bottom-right corner. The test builds also restored the original picker artwork for all nine games and the collection app icon.
- Local unlocks show **Achievement earned!** above the achievement name. The runtime supplies 80 known names across eight games. Goat Up 2 has local recording enabled and uses the generic banner if it reports an unlock. An actual Goat Up 2 unlock remains unverified.
- On iPhone and iPad, touches in the margins map to the nearest edge of the game picture. Drags can continue across the edge without lifting your finger. Gridrunner was playtested with this change before it was extended to the shared touch path for all nine games.
